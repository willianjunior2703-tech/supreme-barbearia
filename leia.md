
# Supreme Barbearia

Página de links oficial da Supreme Barbearia.

## Arquivos

- index.html: estrutura da página
- style.css: aparência e responsividade
- script.js: botões PIX
- supreme logo.jpg: logomarca original

## Testar no VS Code

1. Abrir a pasta supreme-barbearia.
2. Instalar a extensão Live Server.
3. Abrir index.html.
4. Clicar em Open with Live Server.
5. Testar os links e os botões PIX.

## Publicar no GitHub Pages

1. Criar um repositório público no GitHub.
2. Enviar todos os arquivos para a raiz.
3. Abrir Settings > Pages.
4. Selecionar Deploy from a branch.
5. Selecionar main e /(root).
6. Salvar e aguardar a publicação.

## Segurança

- Utilizar HTTPS.
- Não publicar senhas ou tokens.
- Conferir as chaves PIX antes da publicação.
- Testar os links em celular e computador.
- Manter os arquivos HTML, CSS e JS juntos.

## Observações

O site utiliza Google Fonts.

A página não possui banco de dados nem login.

O GitHub Pages não permite configurar livremente
todos os cabeçalhos HTTP de segurança.

A política CSP no HTML fornece proteção parcial,
mas não substitui configurações do servidor.
